# Reference reels

Put 5–10 reels here in the style you want: your own past reels, or creators
whose editing you admire. Then run:

```
python tools/analyze_reference.py
```

It measures each reel (length, cuts, pace, words per minute) and makes a
contact sheet per reel in `reference/_analysis/`. The agent uses that to write
your style pack.

Only add videos you're allowed to keep for study. Everything in this folder
except this README is git-ignored: it never goes into the repo.
