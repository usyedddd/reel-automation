# Style packs

A style pack is the written rulebook for how your reels look, sound and flow.
The agent writes yours during onboarding from your reference reels (see
`AGENTS.md`), using `_template.md`, and follows it for every reel.

Your style pack is personal, so `styles/*` is git-ignored except this README
and the template. Delete that line from `.gitignore` if you want to commit yours.
